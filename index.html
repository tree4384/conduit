    電線管選定

    配管ごとにケーブルと本数を入れて「計算する」を押すと、管種ごとの太さと占積率が出ます。断面図と選定書(PDF・Excel)、断面図のDXFも作れます。

    共通の条件

    占積率32%なら1本でもほぼ満たします。48%で選ぶときに効いてきます。

    結果の表と選定書に並べる管種

    計算のしくみと根拠

    ケーブルの断面積 = π ×(外径 ÷ 2)²。被覆を含む仕上がり外径で、0.1mm²に丸めます。本数をかけて足したものが断面積の合計です。

    管の太さは、断面積の合計が管の内断面積の32%以下になる最小の太さです(内線規程 3110-5の考え方)。管の屈曲が少なく、引き入れ・引き替えが容易な場合は48%以下で選べます。どちらで選ぶかは配管ごとに決めてください。各管の許容断面積(内断面積×32%・48%)は1mm²未満を切り捨てています。

    ケーブル1本のときの「内径 ≧ 外径 × 1.5」は、内線規程 3165節(ケーブルを管に収める場合)の考え方による確認です。共通の条件でオン・オフできます。

    管の内径は次の値です。厚鋼・薄鋼・ねじなし電線管は JIS C 8305 の外径と厚さから求めた値。VE管は JIS C 8430 の内径。PF管・CD管は JIS C 8411 製品の近似内径で、PFは安全側に PFD(複層管)の値を使っています(PFD 42は40mm、54は52mm。PFS は42・54mm)。MFXは未来工業「ミラレックスR」(PFS、JIS C 8411)のカタログ値。FEP管は JIS C 3653 附属書1相当の古河電工「エフレックス」の内径(許容差±2〜4mm)です。製品によって内径は少し違うので、使うメーカーのカタログでも確認してください。

    FEP・MFXを地中埋設に使うときは、JIS C 3653 で管の内径をケーブル外径の1.5倍以上(2条以上はケーブルをまとめた外接円の1.5倍以上)にすることになっています。1本のときは共通の条件の1.5倍チェックで確認できます。2本以上のときは別に確認してください。

    ケーブルの外径は次の値です。電力用(IV・HIV・EM-IE・VVR・CV・CVD・CVT・CVQ・EM-CE系)は矢崎エナジーシステムのカタログ値。VVF・EM-EEFと、IVの2.6mm・3.2mm・250sq以上は住電HST、CV-4Cの100sq以上は古河電工産業電線の値です。CVD・CVT・CVQ・EM-CED・EM-CET・EM-CEQは、より合わせた外径の円で断面積を出しています。VVF・EM-EEFなどの平形は、短径×長径を断面積にしています(1.5倍の確認は長径で見ます)。制御・計装用(CVV・CVVS・CPEV・CPEVS・KPEV・KPEVS)は、送ってもらったExcel「電線管選定ツール ConduitSelector Ver.1.0」(計装屋の知恵袋)の値です。表にないケーブルは「その他」を選んで外径を入れてください。メーカーで外径は1mmくらい違うことがあるので、使うケーブルが決まったら仕様書やカタログで確認してください。
